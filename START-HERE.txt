M.K. IRON • ALBUM ART CREATOR
Based on Mike Knotts's Album-art-creator editor.

Extract the ZIP, then open index.html in Chrome, Edge, Firefox or Safari.
Pick a landscape or photo, enter your lettering, then download the square JPG.
The demo title and artist are editable. Clear either field to omit it.
Photos stay in your browser. Export before closing the page.

Optional Gemini artwork (desktop, Python 3)
Open a terminal in this folder and run:
  Windows: py server.py
  Mac or Linux: python3 server.py
Paste your own Gemini API key at the hidden prompt. An existing GEMINI_API_KEY
environment variable also works. Open http://127.0.0.1:8769 on that computer.
Expand Generate with AI, enter a description and generate. Only the description
goes to Gemini. Provider billing and quotas apply. Ctrl+C stops the server.

For a static website, serve index.html. The local AI bridge runs only on the
owner's computer and accepts requests only from the editor it serves there.

Studio edition
Choose from six artwork presets, or add a photo and use zoom and horizontal
or vertical crop. Crop sliders move an image only along axes with extra image
outside the frame. Choose a lettering composition and typeface.
Export a 3000 or 1080 pixel square in JPG or PNG.
Save project downloads a .mkcover file with your settings and artwork.
Open project resumes it on another device. Embedded photos are optimized
to 3600 pixels on the long edge. Keep original source photos separately.

Editing and proofing
The small proof beneath the canvas shows how the sleeve reads at thumbnail
size. Undo and Redo restore recent committed edits, including photo changes.
Finish a text edit by leaving its field. History is local to the open session.

Reproduce the grade (optional; not required to use the editor)
Install Python 3.9+ and Node.js 20+ with npm. From the extracted folder:
  npm install --prefix qa
  python grade.py
On Windows, "py grade.py" also works. On macOS/Linux use "python3 grade.py".
After dependency setup the checks run offline. The command prints JSON and
exits 0 only if all checks pass. grade-result.json is the recorded run.
Editor checks run the bundled page script with a DOM adapter and Skia.
Bridge checks send real HTTP requests on a temporary loopback port and
substitute a simulated Gemini response. No real credentials are used.
